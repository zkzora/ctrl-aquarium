# CTRL Keyboard website

One paid turn runs one command. Public: 10 credits; Whale: 50. 80% funds the shared reward pool, 20% developer. Each new round starts with up to 300 treasury-funded credits. No fish purchases or hatch timers.

This HTTP frontend requires the /api/keyboard backend and its Base Sepolia contract; it is not a file:// demo. Run `npm run website:build` and `npm run website:preview`. See KEYBOARD_SPEC.md for full rules, contracts, migration and recovery.
