# Start CTRL

Open https://ctrl-aquarium.vercel.app/#room in a browser with an EVM wallet extension.

1. Connect and switch to Base Sepolia.
2. Sign the website login message.
3. Claim 1,500 test credits; test ETH is required for gas.
4. Pay for a keyboard turn (10 Public / 50 Whale) and execute one command.
5. Add a fish or treasure before using a reward command in that habitat and round.
6. Read [KEYBOARD_SPEC.md](KEYBOARD_SPEC.md) for rewards, funding, caps, and black-hole rules.

There is no fish purchase or hatch step in the current version. Never enter a private key in the website.

For local development, deployment, and checks, see [README.md](README.md).
