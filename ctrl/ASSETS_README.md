# CTRL / asset-only package

Open `asset-gallery.html` directly in a modern browser. No application server,
wallet, API key, or dependency installation is needed for this asset preview.

- `assets/`: 106 visual/audio resources, editable source art and derived textures.
- `assets/ASSET_GUIDE.md`: layering, animation frames, pivots, scale and audio cues.
- `assets/asset-manifest.json`: exact paths, dimensions and SHA-256 hashes.
- `assets/VALIDATION_REPORT.json`: resource-format validation evidence.
- `assets/ASSET_LICENSES.md`: provenance and original generation prompt.

The complete application source and `CLAUDE_CODE_SPEC.md` are in the separate
CTRL_WEBSITE_HANDOFF.zip. That application is a partial prototype for Claude Code to
finish. The preview in this archive is not the multiplayer app.

New in revision 2: six creatures, natural shark v2, Whale Aquarium background,
open/empty treasure, black-hole/burst/reveal graphics, stock-inspired demo cards,
and three new original sounds. Company tickers are fictional souvenir labels;
no real stocks, securities, logos, market prices or redemption are supplied.
